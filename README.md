# raizaft.github.io

Portfólio de Raiza Tomazoni — UX/UI e Product Designer.

Site estático (HTML, CSS e um pouco de JavaScript), publicado pelo GitHub Pages.

## Como editar

- Textos e imagens dos projetos ficam em `_build/projects.py`.
- Depois de editar, gere as páginas de novo com:

```
python3 _build/build.py
```

- Estilos em `assets/css/style.css`; imagens em `assets/img/`.
